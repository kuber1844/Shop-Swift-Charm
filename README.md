# Shop Swift Charm

Build a comprehensive single-page e-commerce website featuring a sleek, responsive customer storefront and an integrated admin inventory management panel.

1. Storefront Features: A product grid showing item images, titles, categories, prices, and stock numbers. Include a functional 'Add to Cart' button, a sliding shopping cart summary drawer, and a 'Checkout' button that shows a success modal.

2. Admin Inventory Panel Section: Place this section securely at the bottom or accessible via a clearly marked toggle button. This panel must allow admins to:

	• View a synchronized tabular list of all stock items.

	• Create and add a new product (Form fields: Title, Category, Price, Initial Stock Quantity, Image URL).

	• Update stock levels for existing items directly.

	• Delete an item from the system.

Use modern Tailwind CSS styling, ensure clean layout transitions, and pre-populate the system with 3 sample placeholder items.
